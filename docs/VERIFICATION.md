# Verification

The project is separate from the portfolio. No files in the main portfolio were changed.

- Production build: TypeScript and Vite pass.
- Six cart-domain tests: totals and sizes, merge identity, quantity removal and cap, unique sample requirement, invalid storage rejection and restore.
- Five real Chrome browser flows: scent and notes/size/cart/restore/removal; sample selection and demo completion; rapid switches, keyboard tabs and repeated panel reopening; RU mobile and persistent language with navigation; reduced motion and video-error fallback.
- Native dialog supplies modal focus containment; Escape and focus return tested. No masked typography, so accents/descenders remain visible. Header, quantity and selection targets are touch-usable; visible focus is retained.
- EN/RU layout matrix: 1920×1080, 1440×1000, 768×1024, 390×844 and 320×740. No horizontal overflow or broken loaded images. Main scenes, product, notes, cart, discovery and demo screens visually inspected; screenshots retained.
- Runtime video: 1920×1080, silent, faststart, about 1 MB, one visible film, stops off-screen and with hidden tab/modals. Poster and navigation render immediately; no blocking loader. Reduced motion avoids film and decorative reveals.
- Pricing is explicitly conceptual. No payment inputs, order submission, user account, analytics, third-party checkout or network cart service.

Public-address verification will be recorded after deployment. Reports in evidence/ are evidence of browser execution, not a claim of testing physical devices.

Limits: viewport emulation on Chrome, no physical iPhone/Android or Safari validation. The fragrances and vial designs are fictional portfolio materials. This is a demonstration, not a production commerce backend.
