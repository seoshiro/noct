# NOCT — art direction

Independent fictional niche fragrance brand, created by Beybars Ileskhan for his portfolio. No lotus identity, certifications, testimonials, awards or commercial claims.

Bottle: substantial rounded rectangular smoked-glass monolith with inward-curved lens front, amber liquid at 55% fill, low oval black stone cap and narrow copper collar. Same master object across all materials; no generative bottle variants for individual fragrances.

Palette authored from the brief: plum black #140e16, milk #f0e7da, muted rose #b7aaa8, amber copper #c78b56. Cormorant Garamond headings and IBM Plex Sans UI, locally hosted with licenses. Asymmetric 12-column editorial composition. Fine rules, fragrance index 01/02/03 and a slashed N monogram.

Rhythm: full-frame bottle → reading pause → glass detail and aromatic fragments → interactive collection → three-sample ritual → quiet footer. Semantic HTML text and controls throughout.

Motion: premium and restrained. GSAP reveal choreography and glass parallax; interruptible current-value transitions; 120/250/850ms timing scale. Native scrolling retained; Lenis available but unnecessary. Reduced motion uses static composition. Video playback is visibility-based, not scroll seeking.

Applied installed skills: design-dna (authored tokens, no palette sampling claims), GSAP React/performance (scoped context and cleanup), cinematic GSAP/Lenis (scene rhythm), LottieFiles motion-design (hierarchy), Emil Kowalski animate (interruptions and input feedback). React Bits is a component source rather than an npm engine; no component is needed here. Three.js is a 3D engine; excluded because the site has no meaningful 3D interaction.
